FAQ

Common sawaal

Play Protect warning kyun aati hai?

Kyunki build self-signed hai (Play Store se nahi aayi). Source code tumhari hi repo mein public hai — chaaho to khud build kar lo. Warning par "Install anyway" dabana safe hai.

Kitni jagah leta hai?

APK 55 KB ka hai, install ke baad ~200 KB. 4 GB RAM wale phone par bhi aaram se chalta hai.

Kya ye mera data kisi ko bhejta hai?

Nahi. App ke andar koi network call sirf wahi hoti hai jo tumhari site load karne ke liye chahiye. Koi telemetry, koi crash reporting nahi.

iPhone par kaise chalega?

iPhone APK install nahi karta. iOS ke liye PWA version hai — Safari mein kholo aur "Add to Home Screen" karo.

Update kaise aayega?

Abhi manual: naya APK download karke upar se install kar do, data bacha rahega. Auto-update next version mein.
