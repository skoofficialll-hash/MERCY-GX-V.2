License

Why the footer says “MIT”

MIT is a software license, not a badge

MIT is one of the shortest and most permissive open-source licenses. It says: anyone may use, copy, modify and even sell this code, as long as they keep the copyright notice and do not hold the author liable.

When a project says “MIT licensed”, it means the source in the repository is published under those terms. It has nothing to do with the price — the app is free either way — and nothing to do with the APK you download, which is a compiled build.

Important, and honest: the words “MIT licensed” only count if a LICENSE file actually exists in the repository. If that file is missing, the code is technically “all rights reserved” by default. Either add a real MIT LICENSE file, or drop the phrase from this page.

FAQ

Before you install

Why does Android warn about the app?

The APK is self-signed rather than distributed through Google Play, so Play Protect labels it as an unknown developer. The source is public in the repository, and every release publishes a SHA-256 checksum. “Install anyway” is expected here.

Can I install both?

Yes. They use different package names, so Lite and Pro live side by side and keep separate history and bookmarks.

What is the Mercy search engine in the chooser?

It is the project's own search server — a small crawler, index and ranking engine. You point the browser at your server URL and searches run against that index instead of a third party. Until you host it, the browser falls back to DuckDuckGo.

Does either build collect data?

No. No accounts, no analytics, no advertising SDK. History, bookmarks and settings stay in the app's own storage and disappear when you clear them or uninstall.

iPhone?

Not yet. iOS cannot install APKs, and a GeckoView browser there would need a Mac to build and sign.
