What it is

Small app. Real browser.

Built on the Chromium engine already inside Android, so pages render exactly like they do in Chrome — without the weight, the ads or the sign-in.

Real websites

Any address you type loads in the WebView engine. Back, forward, reload and home sit in the toolbar, one thumb away.

Gamehub new tab

Five games ship inside the app: Grid Runner, Brickfall, 2048, Memory Deck and Aim Lab. They run offline and keep your best scores.

Updates itself

Once a day the app checks for a new release. If one exists, it shows what changed and installs it for you — no store, no manual downloads.

Bookmarks and history

Save a page from the menu, find it again in history. Two hundred entries, stored on the device, wiped in one tap.

Downloads that land

Any file you tap goes straight to your Downloads folder through Android's own download manager, with a notification when it finishes.

Nothing leaves the phone

No analytics, no crash reporting, no advertising SDK. History, bookmarks and scores stay in local storage until you clear them.

FAQ

Questions worth answering

Why does Android warn about this app?

The APK is signed with a self-signed key rather than distributed through Google Play, so Play Protect labels it as an unknown developer. The source is public in the repository — you can read it, build it yourself, or compare the checksum below. Tapping “Install anyway” is expected here.

How do updates work?

Once a day, and whenever you tap Check for updates, the app asks GitHub for the newest release. If it is newer than what you have, it shows the changelog, downloads the APK and opens the system installer. Your history, bookmarks and scores are kept, because the package name does not change.

Does it collect anything?

No. There is no account, no analytics and no advertising code in the app. History, bookmarks and scores live in the app's private storage. The only network calls are the pages you open and the daily update check.

Will it work on an older phone?

It needs Android 7.0 (API 24) or newer. The APK is 55 KB, so the download is trivial on any connection, and it runs on phones with 2 GB of RAM.

Is there an iPhone version?

Not yet. iOS does not allow installing APKs, and a WebView browser there has to be built and signed on a Mac. The gamehub alone works as a web app on iPhone.

Can I build it myself?

Yes. The repository contains the whole Android project and the GitHub Actions workflows that build it. Fork it, change the package name, and your own release feed will work the same way.

Try it for a week

55 KB, one minute to install, and it removes itself completely when you uninstall. If it is not for you, nothing is left behind.
